Demo Bootstrap Navbar

Đây là navbar được tạo bằng các class Bootstrap:

  • navbar - Class chính tạo navbar
  • navbar-expand-lg - Navbar mở rộng trên màn hình lớn
  • navbar-dark bg-dark - Theme tối và nền đen
  • container - Giới hạn độ rộng và căn giữa
  • navbar-brand - Logo/tên thương hiệu
  • navbar-toggler - Nút menu trên mobile
  • navbar-collapse - Phần có thể ẩn/hiện
  • navbar-nav - Container cho các nav items
  • nav-item - Mỗi item trong menu
  • nav-link - Link trong menu
